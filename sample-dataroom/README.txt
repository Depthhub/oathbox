FICTIONAL SAMPLE DATA ROOM - NOT A REAL COMPANY

"Ledgerlight" is an invented B2B invoicing startup used to demo Oathbox.
Every name, number, customer and key in this folder is made up.
The API key in repo/ledgerlight/config.py is a deliberate fake so the
"any hardcoded secrets?" question has something to find. It works nowhere.

Contents
  repo/           small Python service (source + one test file)
  metrics.csv     12 months of MRR, customers and churn
  cap_table.csv   5 holders with ownership percentages

Do not edit these files by hand: their bytes are hashed and the root hash
is committed on NEAR. Use the demo tamper toggle to simulate a change.
